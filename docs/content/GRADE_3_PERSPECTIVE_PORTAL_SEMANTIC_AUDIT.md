# Grade 3 Perspective Portal Semantic Audit

## Method and scope

All 41 questions were reviewed in three passes. Pass A solved each item from only the visible story, objective, prompt, and choices. Pass B compared that independent answer with the authored key, explanation, evidence, and guide. Pass C challenged every distractor for textual defensibility and construct drift.

The review separately checked character A and character B perspectives, evidence for both, similar/different/partly-similar comparisons, perspective change, and the feeling/trait/narrator/author boundaries. Hot-text segments were matched to the displayed story, every table row retained one mapping, and all bounded Part A x Part B combinations use a direct evidence dependency.
