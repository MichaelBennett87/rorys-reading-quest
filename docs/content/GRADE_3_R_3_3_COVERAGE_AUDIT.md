## Construct validity

The audit rejects fact-only comparisons, shared nouns mistaken for a shared topic, superficial similarities, wording-only differences, one-sided evidence, source reversal, and unsupported author-intent claims. Informational work compares presentation of a common topic. Literary work compares how distinct stories present a common supported theme. Supporting plot, theme, structure, and factual comprehension do not replace the author-presentation construct.
