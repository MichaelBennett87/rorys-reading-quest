# Grade 3 Central Idea Engine Semantic Audit

## Method

All 41 questions were reviewed in three passes.

1. Pass A used only the learner-visible text, prompt, choices, objective, and benchmark to solve the item independently.
2. Pass B compared the independent solution with the authored key, explanation, evidence, guide, lesson, and passage ownership.
3. Pass C challenged every distractor for topic/central-idea confusion, narrow-detail support, summary confusion, minor-detail relevance, whole-text fit, and cross-section ambiguity.

## Construct review

- Stated central idea: explicit statement and cross-section support both remain required where applicable.
- Implied central idea: no single sentence is falsely labeled as the exact statement.
- Topic boundary: topic-only answers remain incomplete.
- Summary boundary: event or fact lists remain summaries rather than central ideas.
- Relevant/minor boundary: keyed supporting details directly develop the same central idea; minor details do not.
- Whole-text fit: every keyed idea fits all three sections.
- Cross-section evidence: each checkpoint includes multiselect and two-part support from separate sections.
- Author-purpose drift: none.
- Claim/evidence drift: none.
